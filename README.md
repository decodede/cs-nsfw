# cs-nsfw

NSFW Cloudstream extensions.

Source lives on `main`. GitHub Actions builds every plugin and publishes the
`.cs3` files plus `plugins.json` to the `builds` branch.

## Install

Add this repository URL in Cloudstream:

```
https://raw.githubusercontent.com/decodede/cs-nsfw/main/repo.json
```

## Plugins

- **HStream** - hstream.moe. Catalogs: 4K 48FPS, Uncensored, MILF, Succubus,
  Big Boobs. Detail metadata comes from the page's JSON-LD; streams come from
  the site's player API (720p MP4 plus 1080p/2160p DASH when available).
